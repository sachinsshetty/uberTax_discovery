
### Notes
- After running `docker-compose up -d`, log in to pgAdmin at [http://localhost:5050](http://localhost:5050) using the email and password you set in `PGADMIN_DEFAULT_EMAIL` and `PGADMIN_DEFAULT_PASSWORD`.[1][3][4][5]
- When adding a server in pgAdmin, use:
  - **Host name/address:** `db`
  - **Port:** `5432`
  - **Username:** `postgres`
  - **Password:** `postgres`
